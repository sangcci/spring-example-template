`XSRF-TOKEN` cookie와 `X-XSRF-TOKEN` request header는 같은 CSRF token을 전달한다.
`POST`, `PATCH`, `DELETE` 처럼 상태를 변경하는 요청은 두 값을 모두 보내야 하며, 값이 없거나 서로 다르면 `403 SECURITY_INVALID_CSRF_TOKEN` 을 반환한다.
